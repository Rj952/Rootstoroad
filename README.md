# Roots to Road

A living map of the Caribbean. Walk five hundred years of history on one road, and learn to read what AI says about it.

## Put it online with GitHub Pages

1. Sign in at github.com and create a new **public** repository, for example `roots-to-road`.
2. On the repository page, choose **Add file > Upload files**, drag in `index.html`, `map.jpg` and this `README.md`, then commit.
3. Open **Settings > Pages**. Under **Build and deployment**, set the source to **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/roots-to-road/`.

## Add your videos and sources

Open `index.html`, find the block near the bottom that starts with `YOUR LINKS`, and paste a link between the quotes for any place. Save, upload the file again, and the button for that place switches on.

## Privacy

The site collects no personal data. Students' notes stay in their own browser until they choose to copy them.
